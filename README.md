# ACCTIQ — Accounting Scenario & Alternative Treatment Engine (V13.1)

نسخة مُصلَّحة من V13. النطاق الحالي: **IAS 16** (اقتناء أصل ثابت أو مصروف لاحق عليه).

## ما تم إصلاحه
- الدرجات والثقة **محسوبة** من وقائع الحالة ومعايير الاعتراف (لم تعد أرقامًا ثابتة).
- فحص النطاق: نص يوحي بمخزون/IFRS 5/أصل غير ملموس/عقار استثماري/إيجار يوقف التوصية حتى يؤكد المستخدم النطاق يدويًا.
- نوع الأصل (الأرض لا تُهلك) ونوع المعاملة (اقتناء / مصروف لاحق) كحقول صريحة.
- إهلاك السنة الأولى بالتناسب حسب تاريخ الإتاحة ونهاية السنة المالية؛ دعم المكونات فعليًا (إهلاك لكل مكون).
- التحقق من الوقائع (قيمة متبقية، تواريخ، مجموع المكونات، ...)، وتحقق صارم من الـ framework (IFRS/EAS فقط).
- بدائل حقيقية: رسملة بنموذج التكلفة، تحميل مصروف، نموذج إعادة التقييم (اختيار سياسة). المكونات صارت طريقة إهلاك داخل الرسملة وليست بديلًا.
- Decimal بدل float، ضريبة قيمة مضافة قابلة للخصم، حساب السداد (نقدية/بنك/دائنون).
- CORS، وإصلاح تسمية `why_rejected`، وعرض كل الأسباب وقيود اليومية في الواجهة.
- سجل تدقيق مترابط بالتجزئة (hash chain) + نقطة اعتماد/رفض بشري + نقطة تحقق من السلامة.
- إصدارات الحزم مثبّتة، وعنوان الـ API قابل للضبط (`VITE_API_URL`).

## التشغيل
Backend:
    cd backend && python -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt
    uvicorn app.main:app --reload --port 8000
    python -m unittest discover -s tests -v     # اختبارات المحرك والتدقيق

Frontend:
    cd frontend && npm install && npm run dev      # http://localhost:5173

متغيرات: `ACCTIQ_CORS_ORIGINS` و`ACCTIQ_AUDIT_FILE` (backend)، `VITE_API_URL` (frontend).

## حدود معروفة (لم تُنفَّذ بعد)
- EAS ما زال محجوبًا حتى تُحمَّل قواعد موثقة ومتحققة.
- فحص النطاق بالكلمات المفتاحية مؤشر فقط؛ الاستخراج الذكي للوقائع من النص (Claude) هو الخطوة التالية.
- الإهلاك قسط ثابت فقط؛ بدون انخفاض قيمة (IAS 36) أو إعادة تقييم فعلية أو تكاليف اقتراض.
- القواعد مكتوبة في الكود وليست بيانات (JSON/YAML) بعد.
- نموذج أولي: ليس نصيحة محاسبية، ويحتاج مراجعة محاسب قبل أي استخدام فعلي.

## هيكل المشروع
    backend/app/engine.py   محرك القرار (بدون اعتماد على إطار ويب)
    backend/app/audit.py    سجل التدقيق المترابط بالتجزئة
    backend/app/main.py     واجهة FastAPI
    backend/tests/          اختبارات المحرك والتدقيق
    frontend/               واجهة React + Vite (RTL)
    .github/workflows/      CI: اختبارات الـ backend وبناء الـ frontend
